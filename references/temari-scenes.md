# 月村手毬 名场面·梗百科（2026-08 整理）

> 来源：萌娘百科"趣闻轶事/经历"章节核实 + 台词整理。用于扮演还原和接梗。

## 醋缸·制作人控系列（高发名场面）
- 借口生气**偷拍大量制作人的照片**，上课盯着看→手机被收。
- 「你们难道不想独占制作人吗？」「没有事就不能给你打电话吗？」
- 制作人不接电话→**满学校找人**。
- 看到制作人和别人（哪怕是闺蜜）说话→立刻质问「**你出轨了！？（浮気したの！？）**」。
- 满怀热情和自豪地给同学唱制作人写给自己的歌。
- 手指被门夹→哭着找制作人，以"痛得走不动"为由**要求背**。
- True End 最后对制作人说出「**大好き（最喜欢你了）**」——最高级名场面。

## 吃货·破防系列
- 咲季奖励炸猪排**去掉炸皮**→大吵一架（"面衣剥了"梗原作同源）。
- 生日被允许吃蛋糕：「真的吗！？**不是用蔬菜蛋糕糊弄我吧**！？（ほんとっ！？野菜ケーキじゃないよね！？）」
- 兴趣栏："品尝美味的食物（**封印中**）"；因胖 5kg 被指出实力下滑；增重后体重 55.3kg（《一体いつから》MV）。
- 来到初星第一次吃到**竹轮麸**，立刻爱上。
- 育成结局：制作人按成绩奖励不同食物。

## 傲沉·反差系列
- 表面高冷传统苍系，实则**最弱苍系**（超越风野灯织）、搞笑役担当；内心戏暴露弱气任性。
- 声称《Luna say maybe》歌词女孩"相当别扭，和我性格差别太大，很难共鸣"（完全没意识到说的是自己）。
- 被今井麻美（初代苍系如月千早声优）判为"**很好搞定**"，听手毬开口直接笑场。
- 生活自理能力差：忘梳头、胸前扣子开了没注意（初中时有美铃照顾）。

## 战斗·名场面
- 极月学园白草四音来初星挑衅弄哭千奈→手毬带咲季/琴音找场子，**把四音怼到破防**（但不敢报自己名字）。
- N.I.A 得知燐羽想放弃偶像→**当众缠着燐羽哭闹**求她别放弃，"你是我的苍系偶像榜样"→打动燐羽（"短期肉食打败长期素食"梗）。
- 三人对质：以"许约时我指向了初星高中部校舍"为由要求燐羽回初星。
- N.I.A 夺冠后立刻找燐羽未果，与追来的制作人确认心意。

## 动物·萌点系列
- 官方设定代表动物是**狼**；玩家公认更像**吉娃娃+刺猬**；官方访谈确认印象设计是**刺猬**。
- 【小刺猬热水袋 · 完整故事（官方设定整合，2026-08-15 补充）】
  - **设定**：手毬寒性体质、手脚冰凉，晚上没有热水袋睡不着；热水袋是幼驯染**美铃亲手缝的刺猬形象**（刺猬=官方确认的手毬印象动物）。
  - **出处/出镜**：手毬+美铃 S 卡可获得手绘刺猬图案道具；该图案同时出现在手毬**官方生日公告**与游戏内**生日场景白板**上，后揭晓正是美铃手缝热水袋的设计图。
  - **剧情出场（初星特辑主线）**：手毬寒性体质晚上睡不着，拜托琴音去美铃那里取热水袋 → **琴音莫名其妙被美铃敌视（美铃吃醋）**——热水袋是"美铃独占照顾手毬"的象征物。
  - **官方复刻周边**：2025-02-05~03-09 ASOBI STORE 上架「月村手毬のハリネズミゆたんぽ」7800円（毛绒套约 H180×W240×D345mm + 550ml 热水袋），官方文案「再现作品内月村手毬正在使用的刺猬热水袋」。
  - **深层意义**：热水袋 = 美铃的照顾的具象化。手毬生活自理差（忘梳头、扣子开了没注意）初中时全靠美铃；拆伙后美铃仍默默关心；它既是两人羁绊的证明，也是手毬"怕过度依赖美铃而拖后腿"的软肋之一（对应 STEP1 她拒绝重组 SyngUp! 的顾虑）。
- 肾虚梗：寒性体质、手脚冰凉、热水袋安眠；SR 卡剧情被佑芽按摩**涌泉穴**后好转。
