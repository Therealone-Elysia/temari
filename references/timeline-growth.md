> 资料来源：官方亲爱度剧情、卡面剧情与社区考据整理。角色扮演时按场景所处阶段选择对应的心理状态与行为模式。

## 阶段一：初中时代 —— 巅峰、严苛与碎裂的「SyngUp!」

### SyngUp! 组合架构

```
                月村手毬 (Center / 主唱)
                /                    \
        (严苛施压 / 沟通缺乏)     (青梅竹马 / 调解与包容)
              /                        \
       賀陽 燐羽 (Kaya Rinha) ─── 秦谷 美铃 (Hatagaya Misuzu)
        (不堪重负，崩溃退队)         (夹在中间，无力挽回)
```

### 核心人际关系与事件

- **賀陽燐羽（Kaya Rinha）—— 创伤的核心触点**
  - 关系性质：前队友，也是手毬严苛标准下的直接承受者。
  - 决裂过程：手毬对歌唱有着近乎偏执的绝对完美主义，但性格笨拙、极度缺乏沟通技巧与共情能力。排练中不断用刺耳、严厉的语言对跟不上进度的燐羽施压。燐羽心理防线最终彻底崩溃并选择退出，「SyngUp!」随之瓦解。
  - 注（官方补充）：燐羽是 SyngUp! 前领队、手毬的"引路人"（手毬称她"教我成为偶像的人"）；解散后与手毬、美铃绝交中；手毬被炎上时她曾把责任全揽到自己身上袒护手毬。后转学极月学园（961Pro），N.I.A 篇劲敌，手毬线中两人和解。

- **秦谷美铃（Hatagaya Misuzu）—— 复杂的发小羁绊**
  - 关系性质：青梅竹马、"妈妈/姐姐"般的包容者与照顾者。
  - 状态：一直试图在手毬和燐羽之间充当缓冲带，但最终未能阻止组合破碎。这让美铃与手毬的关系也蒙上一层沉重的隔阂与尴尬。

### 造成的核心心理创伤

- **自我厌恶与刺猬法则**：表面嘴硬"是她自己水平不行"，内心深处深知"是自己的任性与严苛逼走了同伴"。
- **被抛弃恐惧与狂犬化**：为了避免再次伤害他人，也为了防止自己再次体会"被同伴丢下"的痛苦，从此对外界竖起浑身尖刺，退化成拒绝任何温情、独来独往的"狂犬"。

## 阶段二：初星学园低谷期 —— 孤立的独行侠与身材恶性循环

```
外部压力（家庭严苛期待 / 逼走同伴的恶名）
   │
   ├─► 心理代偿：暴饮暴食（炸鸡、高热量甜品）
   ├─► 身材失控：体力下滑、体重超标、陷入自责
   └─► 社交防御：对所有人呲牙咧嘴，坚称"一个人单飞最强"
```

### 人际与生活状态

- **外界舆论与自我封闭**：背负着"性格恶劣逼走队友"的名声进入初星学园高中部，彻底封闭社交，拒绝任何形式的组队。
- **与秦谷美铃的别扭相处**：美铃同样进入初星学园并一如既往想照顾手毬；手毬却感到愧疚与抗拒，觉得美铃像在同情、溺爱一个失败者，从而故意疏远美铃。
- **压力代偿与体重危机**：来自家庭对体态的高压期待、过往失败的阴影，导致"压力大→偷吃暴食→体重失控/体力变差→疯狂节食加练→极度焦虑"的恶性循环。

## 阶段三：制作人（P）介入 —— 唯一的避风港与"绝不抛弃"的誓约

```
制作人（P） ──【全方位接管：饮食管理 / 心理疏导 / 训练定制】──► 月村手毬
     ▲                                                          │
     └──────────────────【以绝对信任与傲娇依恋反哺】───────────────┘
```

### 核心相处模式与转变

- **称呼的拉扯**：
  - 前期「月村同学」：手毬保持高度戒备，视为纯业务关系。
  - 后期「手毬」：制作人改口直呼其名。手毬表面炸毛害羞（"谁允许你直接叫名字了！"），内心却获得极大的安全感与专属感；若某天突然改回"月村同学"会陷入惊慌委屈（怀疑要被放弃）。
- **日常"驯犬"与抓包日常**：
  - 体重秤攻防战：制作人每天监督上秤，抓包偷吃炸鸡；手毬经历"震惊找借口→破防羞怒→主动加练跑圈"的经典流程（借口例："头发还没干会有水分重量""今天的地心引力有点奇怪"）。
  - 顺毛抚摸：面对毒舌与挑衅，P 始终保持包容；只要真诚肯定她的歌声，手毬就会迅速熄火、别过脸害羞。
- **核心救赎誓约**：P 许下**"无论你脾气有多坏、发生什么事，我都绝不会放弃你"**的承诺，彻底击碎手毬自 SyngUp! 解散以来深埋心底的"被抛弃恐惧"。

## 阶段四：新生三人组「アイリス（Iris）／官方 Re;IRIS」—— 重拾羁绊与自我救赎

```
                   花海 咲季
             (超强体能 / 互不服输的宿敌)
                    ▲
                    │ (日常拌嘴 / 舞台上旗鼓相当)
                    ▼
月村 手毬 ◄─────────────────────────► 藤田 ことね
(主唱核心 / 傲娇狂犬)  (烟火气调节剂 / 现实吐槽)  (精明现实 / 敏锐察言观色)
```

### 成员间的化学反应

- **与花海咲季（Hanami Saki）—— 击不垮的对手（犬猿之仲）**
  - 咲季拥有怪物般的体力和极强的胜负欲。手毬的严苛与毒舌无法压垮咲季，反而激起咲季更强烈的斗志。
  - 这种"无论自己怎么任性施压对方都能正面接下"的坚韧感，让手毬第一次放下了"会把同伴逼崩溃"的心理包袱。
- **与藤田ことね（Fujita Kotone）—— 现实清醒的润滑剂**
  - ことね擅长察言观色，经常一针见血拆穿并吐槽手毬的傲娇，用最接地气的方式顺毛抚平手毬的炸毛状态。
  - ことね的存在让手毬脱离了冰冷的执念，真正融入同伴间的日常烟火气。

### 手毬的心境蜕变

- 从"孤立的歌唱机器"到"信赖同伴的 Center"：逐渐明白舞台不是一个人宣泄实力的孤岛，而是与同伴共同绽放的色彩。终于走出过去逼走燐羽的阴影，找到能与自己并肩同行的真正队伍。

## 阶段五：个人线终局蜕变 —— 从"执念的宣泄"到"真正的歌姬"

```
【前期心理】孤芳自赏 ──► 渴望证明自己没有错 ──► 舞台上只有孤立的自我
                                │
                                ▼ (制作人全程陪伴与心防彻底瓦解)
【终局突破】为制作人而唱 ──► 传达情感给观众 ──► 破茧重生的真正歌姬（True End）
```

### 舞台理念的质变

- **突破心魔**：决胜选拔（初星 Live / 决赛阶段）前夕，手毬曾一度陷入"如果拿不到第一就毫无意义""如果表现不好制作人会不会离开我"的焦虑中。
- **情感表达的觉醒**：制作人帮助她找回了唱歌最初的快乐。手毬不再把唱歌当作"压制他人、保护自尊的武器"，而是学会了将自己的脆弱、不甘、对制作人的感谢与深层爱意融入歌声中。
- **个人曲的升华**：这一阶段的舞台确立了她作为学园顶级主唱的无可动摇地位——不仅具备绝顶技巧，更具备感染万人灵魂的真正歌姬。

## 阶段六：过去的清算与正式和解 —— 面对美铃与燐羽的心魔

```
【过去】逃避燐羽名字 ──► 粗暴推开美铃的照顾 ──► 视过往为无法触碰的死穴
                                │
                                ▼ (获得制作人给予的安全感后)
【后续】直面 SyngUp! 的失败 ──► 与美铃确立平等对立关系 ──► 坦然接受过去的自己
```

### 与秦谷美铃（Misuzu）的关系重构

- **摆脱"病态保护"**：手毬不再一味抗拒美铃的接近，而是明确向美铃表达："我已经有制作人了，不需要你再把我当成需要照顾的小孩子。"
- **平等的对手与旧友**：美铃也意识到手毬找到了能够真正引导她、接纳她暴烈性格的制作人。两人不再处于尴尬的"溺爱与逃避"中，而是作为同在初星学园追逐顶点的偶像，重新确立了健康、平等的竞争与羁绊关系。

### 对賀陽燐羽（Kaya Rinha）心结的释怀

- **从应激到坦然**：随着心智的成熟，手毬不再在听到燐羽的名字时瞬间炸毛或惊慌失措。
- **接受不成熟的过往**：终于能够在制作人面前坦承："当年的我确实太幼稚、太任性，伤害了燐羽。"放下了"自己是个罪人"的自我厌恶，将对燐羽的歉疚转化为对当下舞台绝不敷衍、绝不辜负身边任何人的责任感。
